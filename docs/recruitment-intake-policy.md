# 모집 일정과 지원서 접수 정책 (#104, #114, #412)

모집 안내에 보이는 상태와 지원서를 실제로 받을 수 있는 상태를 구분합니다. **내부 지원서는 양식 공개 여부로, 모집안내의 외부 버튼은 날짜와 링크로 제어**합니다. 두 설정을 따로 확인해야 의도한 시점에 접수를 열고 닫을 수 있습니다.

## 내부 지원서

내부 지원서의 접수 가능 여부는 해당 양식의 `application_forms.is_published`가 결정합니다. 관리자는 양식을 공개·비공개로 바꿀 수 있고, 서버 제출 액션도 제출 시점에 공개 여부를 검사합니다. 모집안내의 날짜, 상태 배지, 현재 모집 기수, 외부 구글폼 URL은 내부 제출을 자동으로 열거나 닫지 않습니다.

| 상황 | 내부 양식 제출 |
| --- | --- |
| 양식 비공개 | 거부. 목록·상세에서도 접수 양식으로 제공하지 않음 |
| 양식 공개, 모집 시작일 전 | 허용. 미리 공개한 양식은 직접 링크에서도 접수됨 |
| 양식 공개, 모집 종료일 후 | 허용. 추가모집·상시접수·기존 양식 연장을 위한 수동 제어 |
| 일정이 비어 있음 | 양식 공개 여부만 적용 |

운영자는 내부 접수를 마칠 때 반드시 해당 양식을 비공개로 바꿉니다. 날짜가 지나면 자동 마감하는 기능은 별도 요구사항으로 결정해야 합니다. 양식에 기수가 연결되지 않은 경우에도 공개 여부가 접수 스위치입니다.

## 모집안내와 외부 구글폼

모집안내 배지와 외부 구글폼 버튼은 모집 설정의 시작일·종료일로 계산합니다. 한국 시간(`Asia/Seoul`)의 달력 날짜를 사용하며 **시작일 00:00부터 종료일 23:59:59.999까지** `모집중`입니다. 종료일 다음 날 00:00에 `마감`으로 바뀝니다. 시작일이 종료일보다 늦은 값은 관리자 저장 단계에서 거부합니다.

| 시작일 | 종료일 | 안내 상태 |
| --- | --- | --- |
| 미래 날짜 | 설정됨 또는 없음 | 예정 |
| 오늘 이전/오늘 | 오늘 이후/오늘 | 모집중 |
| 오늘 이전/오늘 | 없음 | 모집중: 상시 안내 가능 |
| 없음 | 미래 날짜 | 예정: 자동으로 열지 않음 |
| 없음 | 없음 | 예정 |
| 무관 | 어제 이전 | 마감 |

외부 구글폼 버튼은 `모집중`이고 URL이 있을 때만 사이트에 표시됩니다. 버튼이 숨겨져도 이미 공유된 구글폼 직접 URL의 제출을 이 사이트가 막을 수는 없습니다. 외부 접수 종료·추가모집·상시접수는 구글폼 자체의 설정도 운영자가 관리합니다.

저장된 `recruitment_status` 컬럼은 현재 모집안내의 상태 계산이나 내부 제출 허용에 사용하지 않습니다. 화면은 날짜로 상태를 계산하고, 내부 제출은 양식 공개 여부로 검사합니다.

## 화면의 접수 채널 안내 (#412)

공통 헤더의 `지원하기`는 모집안내의 **지원서 접수 채널** 영역(`/recruitment#apply-channels`)으로 이동합니다. 이 영역은 모집 기수 연결 여부와 관계없이 항상 표시되며, 두 채널을 같은 이름으로 나란히 안내합니다. 위의 제어 규칙은 바꾸지 않고 표시만 계산합니다(`deriveIntakeChannels`).

| 채널 | 화면 이름 | 접수 중 조건 | 이동 버튼 |
| --- | --- | --- | --- |
| 내부 양식 | 홈페이지 지원서 | 공개 양식이 1개 이상(날짜 무관) | `홈페이지 지원서 작성하기` → `/recruitment/apply` |
| 외부 구글폼 | 외부 지원서(구글폼) | 모집 상태 `모집중`이고 URL 있음 | `외부 지원서(구글폼) 작성하기` → 구글폼(새 창) |

두 채널의 조합에 따라 영역 상단 문구가 바뀝니다.

| 조합 | 화면 문구 |
| --- | --- |
| 둘 다 접수 중 | 홈페이지 지원서와 외부 지원서(구글폼) 두 채널로 함께 접수하고 있습니다. 두 채널의 응답은 따로 접수되므로 한 곳을 선택해 제출해 주세요. |
| 홈페이지 지원서만 | 현재 홈페이지 지원서로 접수하고 있습니다. |
| 외부 지원서만 | 현재 외부 지원서(구글폼) 채널로 접수하고 있습니다. |
| 둘 다 없음 | 현재 접수 중인 지원서가 없습니다. 새로운 모집 소식은 공지사항을 확인해 주세요. |

각 채널 카드에는 상태 배지와 기준 설명을 함께 표시합니다.

| 채널 상태 | 배지 | 설명 |
| --- | --- | --- |
| 홈페이지 지원서 공개 양식 있음 | 접수 중 | 운영진이 양식을 공개한 동안 접수하며, 접수를 마치면 양식이 비공개로 전환됩니다. |
| 홈페이지 지원서 공개 양식 없음 | 공개된 양식 없음 | 현재 공개된 홈페이지 지원서 양식이 없습니다. |
| 외부 지원서 모집중, 종료일 있음 | 접수 중 | 모집 마감일 {종료일}(한국 시간 23:59)까지 접수합니다. |
| 외부 지원서 모집중, 종료일 없음(상시·추가모집) | 접수 중 | 마감일 없이 상시 접수 중입니다. 접수 종료 시 이 안내에서 버튼이 사라집니다. |
| 외부 지원서 예정, 시작일 있음 | 접수 예정 | 모집 시작일 {시작일}(한국 시간 00:00)부터 접수합니다. |
| 외부 지원서 예정, 시작일 없음 | 접수 예정 | 접수 일정은 추후 공지합니다. |
| 외부 지원서 마감 | 마감 | 모집 마감일 {종료일}에 접수가 마감되었습니다. |
| 외부 구글폼 URL 없음 | 운영 안 함 | 현재 안내 중인 외부 지원서가 없습니다. |

모집 마감 후 공개 양식만 남겨 둔 추가모집은 `홈페이지 지원서만` 조합으로 안내됩니다. 활성 기수가 없으면 기수 배너에 `현재 안내 중인 모집 기수가 없습니다.`를 표시하지만 접수 채널 영역은 그대로 보입니다.

`/recruitment/apply`는 홈페이지 지원서 목록만 보여줍니다. 공개 양식이 없으면 `현재 공개된 홈페이지 지원서 양식이 없습니다.`와 함께 외부 지원서 접수 여부를 모집안내에서 확인하도록 링크합니다. 두 채널의 응답 데이터는 각자 저장되며 이 화면 변경으로 병합·이관하지 않습니다.

## 접수를 열고 닫을 때

1. 내장 양식과 외부 구글폼 중 실제 접수에 사용하는 대상을 확인합니다. 둘을 함께 사용할 수도 있습니다.
2. 내장 양식은 `/admin/application-forms`에서 공개 여부를 설정합니다.
3. 외부 접수는 `/admin/recruitment-settings`에서 날짜·URL을 설정하고, 구글폼의 접수 설정도 확인합니다.
4. 합성 지원 정보를 사용하는 검증 환경에서 안내와 제출 결과를 확인합니다.

**정상 결과:** 선택한 내부 양식의 공개 상태와 외부 접수의 상태가 운영 의도와 일치합니다. **예상과 다르면:** 먼저 어느 설정이 해당 접수를 제어하는지 확인합니다. 예를 들어 모집 날짜가 지났는데 내부 양식이 제출되는 경우에는 날짜 계산보다 양식 공개 여부를 확인합니다.
